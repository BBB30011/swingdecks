# GOVERNANCE & SCIENTIFIC FIREWALL

## 1. Scientific Distinctions
Preserve the following progression:
FACT → OBSERVATION → INTERPRETATION → HYPOTHESIS → EXPERIMENT → CONCLUSION

Do not equate:
- Correlation with Causality
- Specificity with Alpha
- Observation with Validated Hypothesis
- Hypothesis with Production Strategy
- Backtest with Proof
- MFE with Directional Edge

## 2. Missingness Rules
- NO_EVIDENCE_IN_DATASET != VERIFIED_NO_EVENT
- LIMITED != READY
- BLOCKED != READY
- UNKNOWN != FALSE

## 3. Data Integrity
- Point-In-Time (PIT) integrity does not equal causal validity.
- SHA256 integrity does not equal source authenticity or completeness.
- Do NOT alter scientific results (e.g., modifying definitions, tuning parameters to search for significance, or removing unfavorable observations).
