# SwingDeck AI Swing Trading Desk

SwingDeck is a decision-support project designed to assist in the analysis and execution of swing trading opportunities in the Indonesian Stock Exchange (IDX).

## Core Purpose
To transition from asking **"What is moving?"** to understanding **"Why is it moving, how does it relate to its peers, and should we act?"**

The system assists the human operator in the workflow:
`SCAN → SELECT → BUY → HOLD → SELL → CASH → SCAN AGAIN`

SwingDeck acts as a highly governed, evidence-based AI decision support system. It is **not** an autonomous execution bot.

## Architecture

SwingDeck uses a strict **3-Agent Architecture** backed by a dual-engine data foundation:

1. **Information Intelligence Foundation**: 
   - **Parquet**: Stores vast, append-only OHLCV quantitative time-series data.
   - **DuckDB**: Powers the Relational Intelligence Graph (`dim_entity`, `fact_relationship`, `fact_exposure`, `fact_event`). This ensures Point-In-Time (PIT) safety, Contextual Peer tracking, and Asymmetric Counterfactual detection.
   
2. **Agent 1: Quant & Market Scanner**: Python-driven quantitative analysis focusing on what is moving.
3. **Agent 2: Market Intelligence & Red Team**: Driven by the DuckDB foundation to query relationships, test hypotheses, and build the Bear Case using evidence.
4. **Agent 3: Investment Committee**: Synthesizes inputs into risk-controlled position sizing.

## Principles

- **No Autonomous Trading**: The system provides analysis and evidence. The operator executes.
- **Evidence-Backed**: Agent 2 cannot hallucinate ownership, exposure, or political relationships. If no evidence exists, attribution defaults to `UNKNOWN`.
- **Reproducibility**: All historical data is strictly versioned and PIT-isolated. Re-running historical backtests will always yield the same outputs.
- **Specificity ≠ Alpha**: A stock moving differently from its peers is a candidate for investigation, not an automatic BUY signal.
